# 城市公共阅读资源数据挖掘与可视化分析原型系统

## 项目简介
本项目旨在通过爬虫采集城市公共阅读场馆数据，进行清洗、入库、多维指标分析，并最终通过 PyQt 桌面软件进行可视化展示。

## 团队分工 (4人)
*   **A (爬虫)**：负责目标网站调研、数据采集、原始数据输出。
*   **B (数据库+清洗)**：负责数据清洗、SQLite 数据库设计、提供读写接口。
*   **C (数据分析)**：负责指标建模、区域密度计算、文本标签提取。
*   **D (GUI+集成)**：负责 PyQt 界面搭建、Matplotlib 可视化、整合 ABC 模块。

## 目录结构
*   `docs/` ：存放立项报告、答辩幻灯片、会议记录
*   `data/` ：存放爬虫原始数据（.json）和清洗后的数据（.csv）
*   `src/` ：存放代码
    *   `src/A_crawler/` ：爬虫代码
    *   `src/B_database/` ：数据库和清洗代码
    *   `src/C_analysis/` ：分析代码
    *   `src/D_gui/` ：界面代码
*   `requirements.txt` ：项目依赖库（统一放在根目录）
